# Shard blocks (`modules/shardblock`)

**The only source of shards** (owner 1 Nov 2026: "shards only from blocks, no other rewards"; build spec ECON-SHARDS, PROVISIONAL while cards C1/C13 are in review). A placeable island block (`shard_block`, footer RARE MATERIAL, looks like stone: `block.active-material` infested stone, regrowing: `block.depleted-material` bedrock). Players get it from crates (Blaze 0.5, Inferno 1, Phoenix 2, Eclipse 3, Conqueror 2 weight), from staff (`/shardblock give`) and later the credit shop (contract: `ShardBlockService#create`). It is a normal tradeable item (AH, `/trade`).

| Command | Description | Permission | Status |
|---|---|---|---|
| `/shardblock give <player> [amount]` | Gives shard blocks (inventory first, the rest to `/box`); amount 1-64, tab completion `1 4 16`; audited `shard_block_give` | `skyblock.staff.shardblock.give` (admin) | ✅ |
| `/shardblock info` | The shard block you look at (up to `interaction.look-range`, 6): id, placer, island, respawn and double level, ready or regrowing, breaks, shards paid | `skyblock.staff.shardblock.view` (mod) | ✅ |
| `/shardblock remove` | Removes the shard block you look at (asks to confirm): row archived (`shard_blocks_archive`, reason `staff`), block to air, the item **with its levels** to the placer's `/box`; audited `shard_block_remove` | `skyblock.staff.shardblock.remove` (admin) | ✅ |
| `/shardblock stats` | Blocks placed, shards paid today and in total (live + archived blocks), the islands with the most blocks (`stats.top`, 5) | `skyblock.staff.shardblock.view` (mod) | ✅ |

`/shardblock` itself needs `skyblock.staff.shardblock.view`. Players have no command: they use the block (help topic `/help shards`).

**Playing:** place it on your island (`worlds`, island role key **`shard-blocks`**: default Admin, Mod, Member; coop players and visitors never; permission `skyblock.shardblock.use`, everyone). At most `block.max-per-island` (4) per island. Break it: **+1 shard** (`shards.per-break`; a double roll pays 2) to your **active profile** (ledger reason `shard_block`), the block turns to bedrock and regrows after `levels.respawn-seconds` (30 min at level 0). Left-click while regrowing shows `Regrows in ...`. Right-click opens the menu: wallet, **Faster Respawn** (crystals: 100/300/900/2,700/8,100 → 25/20/15/10/7 min), **Double Chance** (shards: 10/25/50/100/200 → 5/10/15/20/25%), **Pick Up** (placer or a member with the `settings` role key; the block comes back with its levels, inventory full → `/box`). Upgrades are paid by the clicking player's profile (ledger `shardblk_upgrade`), the block keeps the levels.

**Bounds and safety:** max `shards.daily-cap-per-profile` (100) shards per profile per `shards.cap-zone` day (Europe/Oslo), checked inside the payout transaction; one break per `interaction.break-gap-ms` (400) per player; nothing accumulates while away. Vanilla breaking never happens on a shard block (always cancelled, no drops, no XP, creative too). The payout is one database transaction: shard deposit + block `regrowing` (conditional on its break count) + daily counter (conditional on the cap); a double click, a second server or a replay pays once (`shard_block:<id>:<breaks>` idempotency key). Upgrades: conditional `UPDATE ... WHERE level = from` in the same transaction as the price (two buyers pay once). Pistons, explosions (TNT, creepers), fluids, endermen/withers/falling blocks, fire, fading, buckets and dispensers never move, break or place a shard block. Placing follows the spawner pattern (player file saved without the item, then the row). Pick-up: the row is archived first, then the item is given. Island disband/reset/delete archives the island's blocks (reason `island_removed`). `enabled: false` = blocks stay, nothing pays.

**Audit** (category `island`): `shard_block_place`, `shard_block_break` (one row per profile every `audit.batch-seconds`, 60, with breaks and shards), `shard_block_upgrade`, `shard_block_pickup`, `shard_block_remove`, `shard_block_archive`; category `item`: `shard_block_give`. Economy watch rule `rules.shard-block.*` alerts when one profile gets `amount` (50) shards from shard blocks in one hour.

Data: `shard_blocks`, `shard_blocks_archive` (never deleted by the plugin), `shard_block_daily` (rows older than `daily.keep-days`, 14, purged weekly). Settings `shardblock.yml`, texts `messages/shardblock.yml`, grants `server/permissions/shardblock.txt`.
