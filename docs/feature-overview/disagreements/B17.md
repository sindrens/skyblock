## C. Why both owner bugs happen (confirmed by reading, not reproduced)
1. **Starter chest not fully reset after disband and re-create.** A disband never touches `starter_claims`. The new island's chest gets the plain items and the Field Guide, but the five tools only if the profile has no claim in the last 24 h (`ToolTracker:76-79`, `StarterKitContents:55-65`).
2. **A friend who joins loses tools.**
   - (a) A disband wipes inventory and ender chest of every online member profile (`IslandsConfig:284-306`, `KickBackups`).
   - (b) The "Starter pack on joining a team" is given only while the tutorial is incomplete (`TutorialListener:361-373`) and once per account (`TutorialStore:205-207`).
   - (c) The tools again hit the 24 h claim.
   - So a finished account or a second profile that joins a team gets no tools; only the Forge "Starter kit" button remains.
3. **Invite refusal text** ("You already have an island. Leave it first.", `islands.yml:457`) never mentions switching to an empty profile; decision 254's "untouched island" handling is not built at all.

## D. Risks found
1. **Death drops are untagged** (`ProfileGuards:126-138` tags only dropped items and arrows): profile A dies, switches, profile B picks up A's death drops. A hole in P4, unless keepInventory is on (not found in repo config).
2. **A failed `consumeState`** is only logged (PSI:748-751, 222-225); the stale row is re-applied at next login and silently rolls the profile back.
3. **Cooldown is in memory** (`lastSwitch`, PSI:75), a relog skips it.
4. **Start money per profile key**: a deleted and re-created profile in the same slot gets $1,000 again (the send gate limits harm).
5. **Slot reset is not wired**: `seasonResetSlots` is called by nothing.
6. **Main thread work:** `StateCodec.capture/apply` and `saveData()` on the main thread per switch (PSI:683, 732, 746); acceptable but unmeasured.
7. **Hard-coded:** `LOGIN_TIMEOUT_SECONDS = 5`, `AUTOSAVE_TICKS = 1200`, `"skyblock.cooldown.bypass"` literal, name regex, date format, menu slots, `MAX_SLOTS = 3`, sound ids.
8. **Docs:** `docs/commands/profiles.md:8` repeats the typed-name claim.
