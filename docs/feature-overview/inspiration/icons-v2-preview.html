Phoenix Skyblock: icon set v2 preview

Everything is drawn 16x16 like a vanilla item and shown here at 6x (icons) or 3x (mock chest screens). One dark outline, bright flat colours, one highlight and one shade, chunky 2 px strokes, phoenix/ember palette. Only things that are not a real Minecraft item are custom; everything with a good vanilla item stays that vanilla item (see docs/design/ICON_MAP.md).

How to answer: one line, e.g. nav B, confirm C, shop C, hotbar vanilla (or "nav A except close C"). The generator switches by name: python3 tools/build_icons.py use nav/back B. The ★ marks my pick.
