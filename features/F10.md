# Collection log · id: F10 · status: Draft · version: 1

## In one sentence
A book of everything you have found yourself, with rewards for finishing pages and a big reward for finishing the whole log.

## How it works
- **Status:** planned (M10.10, new module `collection`). Nothing is built. Only two small hooks exist: the island level has a "Collections" source slot (capped at 5% of the level), and the `/menu` Collection button shows "Coming soon".
- **An entry unlocks the first time you get the item yourself:** a drop, a crate open, a quest, a calendar reward or a Black Market buy. Trades, AH buys and `/pay` never count (P10-32), so a log cannot be bought.
- **Per profile** (130). The enchant guide in `/enchanter` stays account-wide (E1). The log's book page is per profile.
- **Pages (plan):** Mine (per tier: ores and rare finds), Forest, Combat (drops per tier), Blueprints, Enchant books, each crate's rewards, Black Market. Later: Farming (Phase 7), Fishing, Bosses and Pets (Phase 8), Events (Phase 9). Unknown entries show `???`.
- **Rewards (P10-33):**
  - Page milestones at 25 / 50 / 75 / 100% give collection points. 1 point per milestone feeds the island level (source "Collections").
  - A full page gives a page title and 1 Blaze key.
  - The whole log gives the mythic title **Keeper of Ashes**, 1 Phoenix key and the secret set (SE2).
- **Season reset:** the log goes with the profile. The best % of each season is saved for history.

## What the player sees
- `/collection` (plan), also the Collection button in `/menu`. A paged menu with one page per area. Missing entries show `???`. Found entries show the item and where you first got it (proposed default).
- A toast when an entry unlocks and a chat line when a page milestone is reached (proposed default).
- Today: the menu button says "Coming soon".

## Rules and limits
- Only your own finds count: drops, crate opens, quests, calendar rewards, Black Market buys. Items from trades, the AH, `/pay` or other players never do.
- Per profile. Nothing moves between profiles (P4). Collection points count only for the profile's island.
- A first find writes one row (`collection_entries`). Later finds do nothing, so there is no ongoing cost (proposed default).
- Titles, keys and the set are given once. Keys from the log are bound (proposed default).
- Bedrock: a normal paged menu, no chat clicks.

## Connections
- Island level (B13): collection points are a source (cap 5%).
- Crates (F5): each crate has a page and gives the keys. Black Market (C13), Depths drops (E5), blueprints (E11), enchants (E12), wardrobe (E13: secret set).
- Quests (F8) and daily rewards (F7): sources of finds. Tags and titles (F4): Keeper of Ashes.
- Progression track (F1), seasons (I5).

## Decided
- 130: the collection log is per profile.
- P10-32: only items you got yourself count, never trades, AH buys or `/pay`.
- P10-33: page milestones give island level points, a full page gives a title + Blaze key, the whole log gives Keeper of Ashes + Phoenix key + the secret set.
- P5-1: island level has 8 sources, collections is one.
- SE2: a secret set can come from completing the collection log.
