# MOTD · id: A7 · status: Draft · version: 1

## In one sentence
The two-line animated message under the server name in the Minecraft server list, with an info box on hover, so the server looks alive and professional before anyone joins.

## How it works
- **Built.** Module `motd`, file `motd.yml`. No commands and no permissions. Edit in the file or `/admin`; apply with `/skyblock reload motd`.
- **Each message** = line 1 + line 2 in MiniMessage with hex colours and gradients. `{brand}` is the SKYBORNMC logo text.
- **Animation:** every server list refresh shows the next frame, so gradients flow (`animation.cycle-seconds: 6`, 12 frames per cycle).
- **Rotation:** `active` lists the messages in order. `mode: rotate` changes every `rotate-seconds` (5). `mode: random` picks at random. **Right now only `discord` is active**: "SKYBORNMC PHOENIX SKYBLOCK" and "Updates at discord.skybornmc.net!".
- **Ready messages:** `coming-soon`, `discord`, `join`, `platforms`, `countdown`, `season-live`, `just-released`, `double-xp`. Put an id into `active` to use it.
- **Countdown:** set `countdown.target` (for example `2027-06-01T18:00`, zone Europe/Oslo). `{countdown}` becomes "2d 1h", "5h 12m" or "12m 30s", then "NOW". Messages with `{countdown}` are skipped while the target is empty.
- **Hover box** (over the player count): 6 lines: name, "Status: Season 1 coming soon", versions, Discord, website. Only the 16 classic colours work there.
- **Centred** automatically (`center: true`).
- **Bedrock:** Geyser passes the Java MOTD and player counts through (`passthrough-motd: true`). How the hex gradients look on Bedrock is not verified.
- **Related server settings** (`server.properties`): whitelist on (testing), `max-players=350`, fallback `motd=` text, `server-icon.png`.
- **Planned (decided):** the maintenance mode from answer 96 (`/maintenance` is only planned) and the exact launch text from answer 95.

## What the player sees
- Line 1: `SKYBORNMC   PHOENIX SKYBLOCK` with the red-orange gradient moving.
- Line 2: a call to action such as "Join Now and rise from the ashes!" or "Join Now | play.skybornmc.net".
- Style rule from the owner (29 Oct): short, general, loud. Brand left, one big headline, a "Join Now" call to action, no grey.
- Hover: "Phoenix Skyblock" header, status, versions, Discord and website.

## Rules and limits
- Pings are cheap to answer: rendered frames are cached (up to 512) and cleared on reload. A countdown makes a new frame each second, which is still small.
- No player data is shown. Only fixed text and the player count.
- Two lines only, English only.
- Exact game versions should not be in the list text (answer 97): the website has them.
- A broken `motd.yml` keeps the previous messages.
- A wrong countdown date or zone only skips the countdown messages and logs an error.
