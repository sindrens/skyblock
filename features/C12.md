# Sell wands · id: C12 · status: Draft · version: 1

## In one sentence
A sell wand is a rare item: right-click a chest on your island and everything sellable inside is sold at the normal `/sell` prices. Nothing is built yet. The crate tables already list it as "coming soon".

## How it works
Nothing is built. The owner wants the idea (59) and "several wand types with rarities and custom features" (E3). The five types below are the proposal in SELL_WANDS.md, not yet approved.
- **The wands (proposed default):**

| Wand | Rarity | Uses | Feature |
|---|---|---|---|
| Copper | Uncommon | 100 | sells one chest |
| Ember | Rare | 500 | sells a double chest and has "Keep Forge materials" |
| Blaze | Epic | 2,000 | +5% sell bonus |
| Phoenix | Legendary | 5,000 | sells every chest in a 5 block radius |
| Eclipse | Mythic | unlimited for one season | +10% sell bonus, radius 8 |

- **Use:** right-click a chest with the wand. The items are sold exactly like the sell chest (C4): same base prices, same live price movement, same sale steps. Each sale costs one use.
- **Bonuses:** the wand's bonus is one more source in the sell bonus. All sources are added up and capped once at +300% (#46), so a wand can never push a player over the cap.
- **Where from:** crates (Sell Wand 100 / 500 / 2,000 uses in the Cinder, Blaze and Inferno tables, chances 4 / 5 / 4%), quests, events and the Black Market (Sell Wand 2,000 uses for 25 shards, C13). No crafting, not sold in `/shop`.
- **Crates today:** the reward is in `crates.yml` as type `coming-soon`, so a crate can roll it but gives nothing real until this card is built.
- **Unique item.** Like enchant books, the uses left are written on the item. It can be traded and auctioned (proposed default), except a wand that came from a bound key, which is bound too (R3-2, decided).
- **Coinmaster:** wand sales give Coinmaster set XP, as normal sales do (WARDROBE).

## What the player sees
- (proposed default) A short result line on each use: "Sold 214 items for $38,420. 1,786 uses left." The line also shows how much the bonus added.
- The wand's lore shows rarity, uses left, radius and bonus. At 0 uses the wand is gone (Eclipse stops working at the season reset).
- (proposed default) Items with no sell price stay in the chest, and the line says how many were skipped.
- Bedrock: a tap on the chest with the wand. No chat input or menu is needed.

## Rules and limits
- Works only on your own island, only in chests you have the Containers permission for. Not on other islands, not at spawn.
- Same prices as `/sell`. If a push limit per player is added to selling (613, C4), wand sales count under it, island members together.
- Never sells what `/sell` never sells: tools, enchant books, money notes, set pieces, starter kit items, dupe-flagged items and staff items.
- No sale without a ledger entry: the items leave the chest and the profile is paid in one safe step, like `/sell`. If paying fails, the items stay.
- The economy watch sees wand sales as normal sales (sell-spike alert, C10). A wand sale is not a way around the +300% cap or the sell spike rule.
- Performance (principle 9): a radius wand looks only at chests inside its radius on that island when used. No scanning, no per-tick work. (proposed default: a short delay of 2 s between uses.)
- A wand is never an exit from principle 2: it only pays the profile that holds it.
- Wands are never sold for real money or gems, because gameplay perks are never sold (REVIEW3 F7).
