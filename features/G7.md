# Scoreboard · id: G7 · status: Built · version: 1

## In one sentence
The panel on the right of the screen shows a different, short layout for each place you stand in (spawn, your island, someone else's island, each Depths zone, the warzone), with only the lines that matter there.

## How it works
- **One sidebar per player.** The layout is picked by place (`hud.yml: places`); the layouts themselves (title and lines) are in `messages/hud.yml: scoreboard.<layout>`.

| Place | Layout | Shows |
|---|---|---|
| Your own island | `island` | Island level and rank, next open note, name and rank, money, crystals, gems |
| Someone else's island (coop counts as a visitor) | `island-visit` | "Visiting <island name>", name and rank, money, crystals, gems |
| Spawn | `spawn` | Name and rank, money, crystals, gems, island level, AFK-pool line while standing in it |
| The Depths: mine, causeways | `depths` | Zone, tier, satchel, Mining level and %, money |
| The Gate / Forest / Combat wing | `depths-gate`, `depths-forest`, `depths-combat` | Zone and tier, the wing's skill level, money |
| Warzone | `warzone` | Combat level, money (placeholder until the warzone exists) |
| Anywhere else | world-named layout, else `default` | Profile, island level |

- **Look (STYLE2):** phoenix gradient title, one blank line under it (FIXES1), bold red `| Section` headers, rows start with a dark red bar, gray labels, white or currency-coloured values, footer `play.skybornmc.net`.
- **Size:** up to 10 lines under the title. Bedrock shows at most 15 lines (`scoreboard.max-lines`).
- **Updates:** each player refreshes every 20 ticks (1 s), spread over the ticks. Only changed lines are sent, so there is no flicker. The layout switches on the tick after a teleport, respawn or world change, and within 1 s when you walk onto another island or Depths zone.
- **Conditional lines:** `if:<placeholder>|<line>` shows only while the value exists. The island level line is hidden until the island has a level (owner answer 275).
- **Switch:** `/settings` > Scoreboard, per profile, applies at once. Chat form: `/settings scoreboard off`.

```
 PHOENIX SKYBLOCK

 | Island
 | Level: Lv 34 #12
 | Profile
 | Pouched · Mod
 | Money: $1.2M

 | Gems: ✦ 120
 play.skybornmc.net
```

## Rules and limits
- Max 10 lines is checked by `SidebarLinesTest` for every bundled layout.
- No online count and no objective line (UX1 removed them). The objective returns with tutorial and quests as its own layout.
- A missing layout falls back: wing, then Depths base, then world-named, then `default`.
- Performance: 300 players means 300 sidebars updated each second (PERFORMANCE.md P-08, partly fixed: changed-line sending and a layout cache). Each player's own scoreboard also carries the tab and nametag teams (G8, P-07).

### The logo (two variants, one layout)
- **Concept:** a cartoony wordmark `PHOENIX` in thick rounded letters with a dark outline, filled with the phoenix gradient from top (red `#FF2D3F`) through orange `#FF6A1A` to gold `#FFC21A` (style.yml `phoenix`), a small rising ember and one tail feather over the `X`; `SKYBLOCK` under it in smaller cream-white letters. The SkybornMC network logo (icy S) stays out of the board: network = frost blue, game = fire (UI_STYLE §1).
- **Size limits:** the sidebar is as wide as its widest line (about 110 to 150 px at normal text), so the wordmark must be at most **96 px wide** and **20 px tall** on screen (texture 192 x 40, drawn at 2x; the owner's final art can be larger in the source but is exported to this size). Height 20 px = the title row plus one blank line (9 px each), so the logo layout spends one extra line: logo row + spacer + 9 lines.
- **Mechanism:** one bitmap font `phoenix:logo` with glyph U+E000 (scoreboard wordmark, 96 x 20) and U+E001 (tab header wordmark, 144 x 28), nothing else in the font (no rank badges, no icons, no text). The scoreboard title is the glyph in plain white (a coloured glyph would tint the art). Starting values `height 20, ascent 16`, tuned on a real client.
- **Who sees it:** Java viewers whose resource-pack answer is LOADED (the pack is forced for Java, I7-R1-02). Everyone else (Bedrock, a failed or fail-open pack, no pack) gets the **plain variant**: `PHOENIX SKYBLOCK` bold in the phoenix gradient, no spacer line. The choice is per viewer at render time (`PackService#hasPack`, Bedrock check); a glyph is never sent to anyone who might see a box. Geyser does not map Java fonts; a Bedrock glyph pack is not planned.
- **Not on:** shared entities (spawn holograms and text displays are seen by everybody, Bedrock would see a box), boss bars (the instruction must stay readable), chat, item names.
- **Generator (placeholder art):** `tools/gen_logo.py`, Python standard library only (`zlib`, `struct` write the PNG). It draws `PHOENIX` in a built-in 5x7 pixel font scaled up with the gradient and outline, `SKYBLOCK` below, and a small ember, then writes `resourcepack/logo/logo_wordmark.png` (192 x 40), `logo_tab.png` (288 x 56), `font/logo.json` (the two providers) and `logo_preview.png` (the logo on the sidebar's dark background at three GUI scales). Re-running it never overwrites a file the owner marked `# owner art` (a sidecar `.keep`). The owner overwrites the two PNGs with real art of the same size.

- The logo is a per-viewer title: `scoreboard.<layout>.title-logo` next to `title`; `hud.yml logo.enabled` (default true), `logo.glyph` (`\uE000`), `logo.spacer-lines` (1). No glyph in any message the viewer can copy; `TypedText` already strips private-use characters from input.
