# Skills · id: E9 · status: Draft · version: 1

## In one sentence
Mining, Foraging and Combat give XP for what you do in The Depths and level up to 150. The first 66 levels unlock Depths tiers and Forge tools. Farming and Fishing are listed as "Coming soon".

## How it works
- **Built:**
  - **XP sources:** Mining and Foraging XP per ore block or log broken in The Depths = the tier XP: 1, 1.5, 2.5, 4, 6, 9, 13, 19, 28, 40, 58, 85 (tier 1 to 12). Island generator blocks and island trees give none (#919). Combat XP per kill by a player: zombie 5, skeleton 10, spider 22, slime 40, drowned 72, witch 135, pillager 250, blaze 420, wither skeleton 700, ravager and evoker 1,200 (`skills.yml: xp`).
  - **Combat XP rules today:** from any mob a player kills, except spawner mobs (also stacked spawners) unless `combat.spawner-mobs-give-xp` is on. Batch kills with stack enchants give XP for the whole batch (about 3,456 XP for one hit on stacked island drowned).
  - **Level curve** (`skills.yml: curve.*`): 600 XP for level 1, each level costs x1.2 more up to level 35, x1.13 up to level 66, then x1.02 up to the max level 150. XP keeps counting after 150 for leaderboards.
  - **Pacing** (balance sheet): Mining 5 about 2 hours for a regular player, Mining 30 about 34 hours (day 11), Mining 66 about 51 days for a grinder only.
  - **Per profile**, and reset each season. Skill XP also feeds tasks, island level (members' skills) and achievements.
  - **Staff:** `/skills set <player> <skill> <levels>` and `/skills add` for admin and owner (#68), audited, the player is told.
  - Other plugins can change XP gains before they are added (the skill XP bonus family is capped at +300%).
- **Planned (decided):**
  - **Combat XP only in Depths combat zones (R3-24)**, like Mining and Foraging. Island mob farms and stack-kill enchants then give none. The Soul Reaper enchant ("+Combat XP from stacked kills") needs a new effect (E12).
  - **Crystals on every level-up**, bigger every 5 levels (#924). Not built.
  - **A small bonus to the skill's own activity per level**, inside the shared caps (#925). Not built. The code says "perks come in Phase 6".
  - **Farming and Fishing** skills with Phase 7.

## What the player sees
- `/skills [player]`: a menu with level, progress bar, XP in the level, total XP, next unlock and how to earn XP. Anyone can look at another player's skills (#922).
- Action bar after gathering: "+12 Mining XP (68%)", at most one line per 1.5 seconds. Turn it off in `/settings` (XP bar).
- Level-up: a title, a sound and a chat line with the next unlock, for example Mining 5 opens Copper.
- Placeholders for scoreboards: `skill_mining_level`, `skill_mining_progress` and the same for foraging and combat.

## Rules and limits
- Anti-abuse: no gathering XP outside The Depths; no Combat XP from spawner mobs; entities tagged `skyblock_no_skill_xp` give none; gains are added in batches and saved every 60 seconds and on quit. Staff changes are audited.
- Skills are per profile, so a new profile starts at 0 (profiles are islands).
- Performance: XP is added in memory per action and saved in batches; the menu is read-only.
- Bedrock: chest menu and action bar only.
- Max level 150 stays a far goal: nobody reaches it in one season.

- 918: Combat XP per kill pays the same XP per hour as mining.
- 919: Mining and Foraging XP only in The Depths. Its Combat part (any non-spawner mob) is replaced by R3-24.
- R3-24: Combat XP only from Depths combat zones.
- 922: anyone can view another player's skills.
- 924: crystals on every level-up, bigger every 5 levels.
- 925: each level gives a small bonus to its own activity, inside the caps.
- 414: a season reset resets player data, so skills start again each season (Depths world stays).
