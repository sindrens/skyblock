# Island notes · id: B9 · status: Built · version: 1

## In one sentence
A shared to-do list for the island team, with a menu, a temporary book and notes you can pin as holograms in the world.

## How it works
- **Open:** `/is notes` or Island menu then "Island notes". Staff can add an island name to read another island's notes (read only, logged).
- **One shared list per island:** max 50 notes (open and done together), each max 200 characters. Each note shows author and date, and who ticked it and when.
- **Menu:** open notes first (newest first), then done ones. Buttons: Add note (type it in chat), Open as book, Clear done notes (manage). Click a note to tick it done or open it again, change its text, pin it here, unpin, or delete (confirm).
- **Temporary book:** writers get a Book and Quill with one open note per page plus an empty page. Closing it saves all changes in one step. Readers get a written book. The book is taken back after saving, after 5 min, on quit, death, profile switch or island removal. It can't be moved, dropped or crafted with.
- **Holograms:** pin a note where you stand (inside the border), max 5 per island. It is a text display that is not saved with the chunk, shows only on its own island, and is removed when the note is ticked done, unpinned or deleted.
- **Who may do what** (matrix rows, own defaults): Read notes (Admin, Mod, Member, Coop), Write notes (Admin, Mod, Member: add, tick, edit or delete your own), Manage notes (Admin, Mod: edit or delete anyone's, clear done). Leader has all three.
- **Alerts:** online members who can read get "<player> added a note: ... [Open]" (`/settings` toggle "New island notes", on). A scoreboard line with the newest open note is a `/settings` toggle, off by default.
- **Deleted notes:** delete and clear only mark notes deleted. Staff see them for 7 days (Deleted notes view), then they are removed for good.

## What the player sees
- Notes menu with a summary: open and done count, "x/50", pins "x/5".
- Chat prompt when adding a note; the note is shown with your name and the date.
- Text is cleaned by the chat filter: links, IPs and phone numbers are blocked, colors and line breaks removed. Coordinates are allowed.

## Rules and limits
- Text goes through the chat filter and is never read as formatting.
- Anti-spam: at least 2 s between two notes from the same player.
- Holograms count toward the stacking module's display-entity limit.
- Every action is logged (`island_note_add`, `_edit`, `_done`, `_reopen`, `_pin`, `_unpin`, `_delete`, `_clear`, `_book`, `_purge`). Blocked text is logged in the chat category.
- Bedrock: the menu uses plain clicks and is the main way. The book is an extra.
