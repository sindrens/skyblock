# Chat · id: G1 · status: Built · version: 1

## In one sentence
One public chat for the whole server. Every line shows rank, name and tag, and filters stop spam, links and bad words. Players get mentions and [item]; staff get chat controls.

## How it works
- **Line format** (chat.yml: `format.chat`): `<title><rank><name><tag> » <message>`. Example: `[MOD] Pouched (Phoenix) » hi`. Rank prefix and name colour come from LuckPerms. A nickname shows with `~`. Players with no rank have no prefix.
- **One public channel.** Staff chat (`/sc`) and island chat (`/is chat`) are separate channels that go through the same checks.
- **Colour codes:** only ranks with a permission can use `&` codes. Colours and formats (`&l &o &n &m`): helper and up. Hex (`&#RRGGBB`): admin and up. Normal players type plain text.
- **Mentions:** typing a player's name or `@name` lights it up for them and plays a sound.
- **`[item]` or `[i]`:** shows the held item with its tooltip. Everyone can use it. 10 s cooldown (`item-show.cooldown-seconds`).
- **Name card:** hover a name to see rank, island and playtime (owner answer 302). Click a name to start `/msg <name>`.
- **Staff controls:** `/chat clear` (`/cc`), `/chat lock` (`/mutechat`), `/chat slow <seconds>`. Staff keep their own chat when it is cleared.
- **Logging:** every line is audited (category chat), including filtered ones with the reason. Kept 30 days.
- **Check order:** staff chat mode, channel, lock, slow mode, new-player delay, rate limit, duplicate, text filter, colours, `[item]`.

## What the player sees
- The chat line above, and the name card: "Rank / Island / Played" with "» CLICK to message".
- Refusals in the red ✘ format: "Too fast. Wait a moment." · "Don't repeat the same message." · "Links to other sites aren't allowed." · "Blocked by the chat filter."
- `/settings` Chat group: Mention sound, Chat colors (show colours in other people's lines), Chat timestamps (off by default), Hide ignored chat (on by default).
- Bedrock: no hover. Names keep their dot (owner answer 303). `[item]` shows only the item name.

## Rules and limits
- Rate limit 4 messages per 5 s. The same message again is blocked for 30 s (`protection.*`).
- Caps: a line with 6+ letters and over 70% capitals is lowercased. TEST_GUIDE says "blocked", the code lowercases.
- New accounts cannot chat for their first 30 s of play on day one (`protection.new-player-seconds`).
- Blocked: links to other sites, server IPs, phone numbers. Allowed domains: skybornmc.net, youtube.com, youtu.be, imgur.com, minecraft.wiki. Mods and up may post links.
- Word filter, English only: mild swearing becomes `***`; slurs and threats block the line and alert staff. The same filter covers signs, books, anvil names, warp names, notes and nicknames (304). The starter word lists still wait for the owner's approval.
- Public chat is English only (rule 7). Staff enforce it; there is no automatic language detection.
- `skyblock.chat.bypass` (mod and up) skips lock, slow mode, rate limit and filters. Muted players are stopped by the moderation module.
- Performance: every viewer gets their own rendered line (hover card, mention check). At 300 viewers this is about 600 parses per public line (PERFORMANCE.md P-05). Not fixed yet.

MC Hub's chat is easy to read because colour carries meaning and event lines are one line each with a short coloured category tag. Everything below is vanilla text.
- **Colour ladder:** name colour = rank colour (G8 sets one distinct colour per rank). Message text is plain gray, values white, as in UI_STYLE §3. Staff names are never mistaken for donors because no two ranks share a colour.
- **Category tags on server event lines (decided):** a short bracket tag in a fixed colour, then plain text. Chat events only (crate wins, store purchases, market news, boosters, events, KOTH), never on player chat.
| Tag | Colour | Example line |
|---|---|---|
| `[Crate]` | flame gold | `[Crate] Steve won a Blaze Key and 2 other rewards.` |
| `[Store]` | brand red | `[Store] Steve bought the Flameheart rank. Thank you!` |
| `[Market]` | money green | `[Market] Sugar cane is up 22% in 24 hours. » /sell` |
| `[Event]` | ember orange | `[Event] Envoys land in 5 minutes. » /warp envoy` |
| `[Booster]` | steel sky | `[Booster] 2x Money for 30 minutes. » /booster` |
  Player names in these lines keep their rank colour; items keep their rarity colour; the tag is the only coloured frame. One line per event, max one per 30 s of the same tag from the auto-announcer, same rule as UI_STYLE §3.3.
- **Clickable text** keeps `[Word]` in the action yellow with a hover text, so a tag colour never looks like a button: tags are bracketed in their own colour and are never underlined or clickable. (GUI-Q6 keeps tooltip names without brackets for the same reason.)
