# Per-player blocks · id: E2 · status: Draft · version: 1

## In one sentence
Every player sees their own ore and logs in The Depths: a block you break looks depleted only for you and comes back after 10 seconds, so 300 players can mine the same field without stealing from each other.

## How it works
- Ore and log blocks are real blocks and never change on the server. A break is cancelled by the plugin, a `ResourceBreakEvent` is fired (drops, skill XP, tool XP, enchants and books listen to it), and only the miner is sent the depleted block.
- **Respawn:** 10 seconds (`depths.yml: engine.default-respawn-seconds`), then the real block is sent back to that player. A timing wheel (1,024 slots) holds the timers, so there is no task per block.
- **Fields:** each tier zone has a field of about 40 x 40 x 3, registered as region `<zone>_<field>` with a list of `{block, depleted, respawn-seconds}`.
- **Depleted look per tier:** Coal shows cobblestone, Copper granite, Iron diorite, Gold smooth sandstone, Redstone cobbled deepslate, Lapis deepslate tiles, Diamond tuff, Emerald mossy cobblestone, Amethyst calcite, Quartz netherrack, Netherite blackstone, Voidstone end stone. Logs show their stripped log.
- **Chunk reloads:** depleted blocks are sent again whenever the server re-sends a chunk to that player.
- **Relog and world change:** running timers are kept per player (up to 4,096), so relogging does not reset ores. A server restart resets everyone.
- **Anti fast-break:** a break faster than 70% of the vanilla time (plus 100 ms for lag) is ignored with no message (#780). Three flags in 10 seconds alert staff and write an audit row.
- **Break speed** uses real item attributes (mining efficiency and break speed), so it works on Bedrock. Area enchants (Vein Rend, Treefeller and others) break only your own copies of blocks, and speed bursts stay under 6 blocks per second.
- **Inside regions:** other blocks cannot be broken and no block can be placed. Builders with `skyblock.depths.build` in creative mode can edit.
- **Planned (decided, REVIEW3 D1):** tier palettes. One "slot" block shows a different ore or log to each player, by their active tier (coal for one player, iron for another, in the same spot). The real block is the tier-1 block, so tier-1 players need no packets.
  - `ResourceBreakEvent` gets `getShownType()` and `getTier()`; XP, drops, hooks and ambient mobs read them instead of the real block.
  - Hardness trap: the client times a break from the shown block, so the anti fast-break check scales by the shown block's hardness.
  - Bedrock: throttle to about 300 blocks a tick per player and skip tier-1 players.

## What the player sees
- You break an ore: it turns into the depleted block (for example cobblestone) and the ore is back after about 10 seconds. A friend next to you still sees the ore.
- Action bar on a non-resource block: "Only resource blocks can be mined here."
- Known quirk: right after a break the real ore may flash for one tick (50 ms).
- Staff: `/depths debug [player]` shows region, depleted counts, timers and break timing.

## Rules and limits
- Performance: a break outside regions is one map lookup. Inside, a few map operations and one event. The tick task only counts while nothing is pending. Memory is capped at 4,096 remembered blocks per player.
- Anti-abuse: silent ignore of impossible breaks; Grim handles movement and reach. A full satchel refuses the break today; the owner decided it should not (E4). Nothing can be dug down: a broken ore shows a solid block.
- Ore must have an exposed face. Builders place only the tier's ore block inside a field cuboid.
- Gathering skill XP only counts in the Depths (#919), so island generator blocks give none.
- Bedrock: no client mods needed; same behaviour as Java.

## Connections
- Zones and fields (E1), tiers and gates (E3), satchel (E4), drops (E5), skills (E9), tools (E10), enchants (E12).
- Visibility (E8) uses the same per-player state; with it on, players at different tiers see each other. Selling (C4) prices the drops.

## Decided
- Phase 4 (29 Oct): ore and logs respawn after 10 seconds; broken blocks are fully personal.
- 780: impossibly fast breaks are ignored silently; staff alert after 3 flags in 10 seconds.
- 783: players in the Depths cannot place blocks or break anything except resources.
- 919: Mining and Foraging XP only in the Depths.
- REVIEW3 D1: tier palettes, one slot block shows a different ore per player (planned).
- REVIEW3 D2: each tier in a shared zone has its own drop table and quantities (E5).

## Open questions
1. The one-tick flash of the real ore after a break. Default: accept it. A packet-level fix would need ProtocolLib or PacketEvents.
2. Fast-break audit rows use category `world` (no anticheat category exists). Add one? Default: no.
3. Should depleted timers survive a server restart? Default: no, a restart resets everyone the same way.
