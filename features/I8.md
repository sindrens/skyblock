# Launch prep · id: I8 · status: Draft · version: 1

## In one sentence
Before opening, the server gets a full balance pass, a 300+ bot load test, a closed beta with a wipe, and a launch checklist that must be true on launch day.

## How it works
PHASE-13-LAUNCH.md is an outline. The owner expects launch in about 3 years, with everything in season 1 (ROADMAP). Milestones below are proposed defaults.
- **Built (groundwork):**
  - A test VPS with deploy scripts (2 vCPU, 4 GB). Production is planned as a dedicated Ryzen-class box with 32-64 GB RAM and a 16-24 GB heap.
  - Whitelist is on (`white-list=true`). The MOTD module has a launch countdown (`motd.yml: countdown.target`, empty = off) and ready messages like "SKYBLOCK OUT NOW!".
  - Raid detection that only alerts staff (more than 15 new accounts in 30 s, `punishments.yml: extras.raid`).
  - Balance model `tools/economy_model.py`, the economy dashboard `/eco admin`, the audit log.
  - A daily backup at 04:30 that keeps 7 days on the same machine. The setup script itself says to add off-site copies before launch.
  - A privacy line in `/rules` ("Chat, private messages and commands are logged for 30 days...") with a link to skybornmc.net/privacy. The privacy page itself is not written.
  - A load test plan (PERFORMANCE.md §5) and a security test plan (SECURITY_ANTI_EXPLOIT.md §5).
- **Not built:** `/maintenance`, the 6 hour off-site backups, the bot load test, the beta process.
- **M13.1 balance pass:** run the model with every system built, fix outliers, the owner approves the final numbers. Sell and shop prices go live on the test server first (650, 692, 711). Rerun the model without the paid sell bonus (it still has `SELL_RANK_MAX=0.15`, REVIEW3 §3). Keep the smooth money curve and re-check the $5M day-3 target (R3-37): the model gives about $12.9M to an 8 h/day grinder and $1.5M to a regular player.
- **M13.2 load test:** bots to 350 players on a staging copy. About 300 Java and 30 Bedrock bots, 10 scenarios (join storm, spawn crowd, 150 miners, 100 farms, boss fight with 150 players, backup under load and more). The review session also suggests an earlier 80-bot run on the test server before the big Depths v2 work (REVIEW3 §6), with the owner's OK as always.
- **M13.3 security pass:** every test in the security plan, plus a dupe hunt with testers. Check that Floodgate passes each Bedrock player's real IP, or the per-IP rules (AFK, ratings, warzone, gems, mini-bosses) treat all Bedrock players as one (REVIEW3 §3).
- **M13.4 closed beta:** 2-4 weeks with invited players, then a full wipe.
- **M13.5 launch checklist:** Mojang check, privacy policy page, rules page, store live, Discord ready, pack checked on a Bedrock phone, backup restore tested for real, maintenance mode tested, staff trained.
- **M13.6 launch week:** countdown in the server list, raid alert 60, extra staff schedule, a daily hotfix window.
- **Before beta:** a Velocity proxy and a hub/lobby server; Geyser and Floodgate move to the proxy (DESIGN §15).

## What the player sees
- Before launch: only whitelisted players join. The server list shows the countdown and "PHOENIX SKYBLOCK - Season 1 starts DATE - Java and Bedrock" (95).
- In maintenance: staff only can join. Others see a friendly closed message (text not written).
- Planned (proposed default): a cosmetic "Beta Tester" title and a short restart at a fixed time each day in launch week.

## Rules and limits
- Acceptance targets for the load test: TPS 20 for 95% of the time, MSPT p95 under 35 ms and p99 under 50 ms, GC pause p99 under 100 ms, database wait p95 under 50 ms, login to ready under 10 s with 300 online.
- Never start a test server without the owner's permission (Q13). Bots run on a staging copy, not on live data.
- Raid alerts rise to 60 new accounts per 30 s in launch week, then go back to 15 (422).
- Pack changes need a Bedrock phone check (78). Nothing is sold before the Mojang guidelines check (RTA-1).
- Privacy: IP data is deleted 12 months after the last login (529). A notice and a privacy page are required (319, 532).
- Bedrock: at least one Bedrock tester must pass the first-hour flow and every menu.
- Performance: the pass is built around 300 players on one server with no per-tick scans.
