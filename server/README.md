# Server configs

Tracked Paper server configuration (server.properties, bukkit.yml, spigot.yml, config/paper-*.yml, start script).
Jars, worlds, logs and player data are ignored (see .gitignore). Download Paper 1.21.11 from https://papermc.io/downloads/paper.

Never commit passwords or tokens. Keep them in a local `.env` or `secrets.yml` (both ignored).
